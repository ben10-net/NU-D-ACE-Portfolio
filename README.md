# NU-D-ACE-Portfolio
An AI-powered student uniform compliance system that uses
computer vision to identify students and detect traditional
uniform violations.

## Project Overview
NU-D ACE is a software engineering project designed to automate
student uniform compliance monitoring through computer vision.

The system integrates facial recognition and object detection
to identify students, detect uniform violations, and record
compliance results through an administrative dashboard.

## Technologies
- Python
- Computer Vision
- FaceNet
- YOLO
- Object Detection
- Facial Recognition
- MySQL
- Web Dashboard

- ## System Features
- Student identification through facial recognition
- Real-time uniform detection
- Uniform violation detection
- Automated violation logging
- Administrative dashboard
- Student compliance records

## Project Status
Academic project — developed as part of a Software Engineering
project at National University–Dasmariñas.
